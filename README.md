# sp-programming-language
A custom mini programming language engine built in Python.
# SP Language Engine

**SP Language** ek simple aur custom mini programming language hai jise Python mein banaya gaya hai. 

## Features
- **Interactive Questions:** `?` lagakar user se sawal pooch sakta hai aur jawab ko `ANSWER` mein save karta hai.
- **Dynamic Output:** Save kiye gaye `ANSWER` ko dobara kisi bhi line mein istemal kar sakta hai.
- **Math Calculator:** Seedhe mathematical calculations (jaise `50*4`) solve kar sakta hai.

## Code Example
```text
<SP>...
PRINT=AAPKA NAAM KYA HAI?.
PRINT=SWAGAT HAI ANSWER.
PRINT=50*4.
<SP>...
```

## Kaise Chalayein
1. Is repository se `sp_engine.py` file download karein.
2. Apne computer ya phone par Python mein run karein.
